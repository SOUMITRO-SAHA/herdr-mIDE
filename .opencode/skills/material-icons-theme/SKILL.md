# Material Icon Theme

Material Icon Theme is the only icon source in herdr-mIDE. Every icon
in this repo comes from here: the file-type icons in the Files panel,
the solid folder pair, any new tree or UI glyph.

## Source Of Truth

Use the current sources, not memory.

1. Repo: https://github.com/material-extensions/vscode-material-icon-theme
   (MIT — see LICENSE at the repo root)
2. **Built icons**: the npm package `material-icon-theme` ships every
   built SVG (`icons/*.svg`, 16×16, color-baked). This is the easiest
   artifact to pull from:
   ```
   curl -sL https://registry.npmjs.org/material-icon-theme/-/material-icon-theme-<version>.tgz | tar -xz package/icons/folder.svg package/icons/folder-open.svg package/LICENSE
   ```
3. `icons/folder.svg` and `icons/folder-open.svg` are NOT in the git
   repo's icons dir — they are generated at build time (folder color is
   configurable upstream). Always take them from the npm package.
4. The npm `generateManifest` export maps file/folder names to icon
   names, same shape as the extension's associations.

## How we use icons in this repo

1. File-type icons land in `mods/mide-files/icons/material/` and the
   association map in `mods/mide-files/icons.js` (SUFFIX/NAMES tables,
   exact-name → longest-dotted-suffix order) — both generated by
   `scripts/update-icons.sh`, which fetches the npm tarball and parses
   the theme's `src/core/icons/fileIcons.ts`. Entries gated behind
   optional icon packs (`enabledFor:`) are skipped, matching upstream's
   defaults; `filenamePatterns` regex entries are skipped too.
2. Folder and tree glyphs live in `mods/mide-files/icons/` (folder.svg,
   folder-open.svg, chevrons).
3. Everything is materialized into `mods/mide-files/icons/` by
   `make assets` (`make dev`/`make sync` do it automatically — the mod
   must stay self-contained for ecosystem installs).
4. **Rewrite the baked fill to `currentColor`** (upstream ships
   `fill="#90a4ae"`): Herdr's `svg()` tint then drives the color, so
   glyphs follow the theme (muted when clean, change-colored underneath)
   instead of a hardcoded hex.
5. Keep the 16×16 viewBox and add no stroke — strokes close the slit in
   the open folder and fatten the glyph.
6. Verify the shape at render size before committing: render a 192px
   copy with `qlmanage -t -s 192` and eyeball it.

## Rules

- Any new icon: look in Material Icon Theme first (523 icons ship in
  this repo — the build prunes everything the map does not
  reference; ~1250 exist upstream). Fetch from the npm tarball, convert
  fills to `currentColor`, drop into `mods/mide-files/icons/`.
- **Every adoption must be credited** in `THIRD-PARTY-NOTICES.md`
  before commit — MIT text, © Material Extensions, modifications noted.
  Notices list only what is actually shipped.
- Material Icon Theme is the **only** icon source in this project — no
  other icon set may be shipped or mixed in.
- Never take icons from GPL sources (study them, draw fresh).
